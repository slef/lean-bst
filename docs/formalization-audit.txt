Formalization scope audit — 2026-11-02

This audit checks the requested results against exported Lean statements,
not merely against build success. Paths are relative to the repository root.

1. Simple unlabelled BST model and conventional-model justification
   Evidence: Models/Rotation/Abstract.lean, Models/Labelled/Abstract.lean,
   Models/Labelled/Ordering/Abstract.lean, Models/Pointer/Abstract.lean, and
   Models/Pointer/Lazy/Online/Abstract.lean (all below RotationBST/).
   Arbitrary inorder key lists determine unique labelled shapes; rotations
   and accesses preserve costs under labelling. Pointer executions simulate
   root accesses, and the reverse simulation has constant overhead with an
   explicitly charged deferred suffix. The online transformer is causal.
   Cost normalization includes a request charge; zero-rotation root accesses
   are not silently treated as zero-cost conventional searches.

2. Executable splaying and working-set consequences
   Evidence: Algorithms/Splay/Algorithm/Abstract.lean and Algorithms/Splay/WorkingSet/Abstract.lean.
   The algorithm is bottom-up zig/zig-zig/zig-zag splay, not move-to-root.
   Bounds/Implications/Abstract.lean proves working set => static optimality
   => static finger for arbitrary Algorithms, independently of splay.
   Bounds/StaticTree/Abstract.lean connects entropy to fixed comparison trees.

3. Sleator–Tarjan's nine numbered results
   Evidence: Algorithms/Splay/{Balance,StaticOptimality,StaticFinger,WorkingSet,
   Unified,Updates,Conditional,Snapshot,Scanning}/Abstract.lean.
   Checked assumptions include first-use working-set number n, startup
   allowances for arbitrary initial trees, coverage conditions where startup
   is removed, positive analysis weights, and nonnegative normalized snapshot
   probabilities. The unified theorem uses the fixed-finger 1985 bound.
   Updates use supplied local ranks and ordered forests. Conditional splaying
   bounds restructuring, not total searches. Scanning is linear from any
   initial shape. Constants and implementation variants are listed in README.
   Top-down and semisplaying implementations, comparison-key rank discovery,
   and allocation-aware pointer updates are not claimed.

4. Arboral geometry and offline equivalence
   Evidence: Models/Geometric/Definitions/Abstract.lean, Models/Equivalence/Abstract.lean,
   Models/Geometric/Abstract.lean, and Algorithms/GreedyASS/Abstract.lean.
   ASS is the closed-rectangle third-point property. Exact cardinality matches
   rooted-region cost with a free initial tree. Rotation and pointer models
   have constant-factor conversions, with initialization charged where needed.
   GreedyASS's executable empty-rectangle sweep is legal and is the unique
   minimum-cardinality completion of the current row.

5. Causal geometric-to-BST simulation
   Evidence: Algorithms/Simulation/Abstract.lean
   and Models/Equivalence/Abstract.lean: online_bst.
   Quantifiers: for every n and geometric OnlineAlgorithm, one BST Algorithm
   works for all starting trees of size n and all valid request sequences.
   Its choices are fixed by prefixes, not by the eventual continuation.
   Rotations <= 6018 * geometric points + 6018 * n.
   Normalized total cost <= 6019 * geometric points + 6018 * n.
   A fixed causal pointer strategy also has a checked linear bound.
   Extraction, root visits, deferred restoration, rebuilding, and nested
   splitting potential are all included. No dynamic-optimality theorem for
   GreedyASS or splay is asserted.

6. Tango results
   Evidence: Algorithms/Tango/Algorithm/{Abstract.lean,Executable/Abstract.lean},
   Algorithms/Tango/Reference/Results.lean, and Bounds/Interleave/Abstract.lean.
   The executable policy maintains canonical preferred paths and nesting,
   serves each requested rank, and has an O(log log n) competitive bound
   against every offline comparator, including arbitrary universe sizes.
   Wilber's interleave lower bound is proved through distinct transition
   points. The implementation uses amortized splay auxiliary trees; the
   paper's red-black auxiliary implementation is not claimed.

7. Readable statements, Lean layout, and upstream basis
   Evidence: the result Abstract.lean modules and their #check_bst_abstract
   invocations; lakefile.toml; RotationBSTTests/Axioms.lean; CI workflows;
   scripts/check_imports.py; Models/Labelled/Mathlib/Abstract.lean.
   All library modules are reachable through import RotationBST. Public
   statement boundaries allow explicit readable foundation modules. The
   entire imported declaration environment is audited for axiom dependencies,
   allowing only propext, Classical.choice, and Quot.sound. There are no proof
   placeholders in the library. Lean and CSLib versions are pinned.
   This is a checked local basis for upstream work, not an upstream submission,
   registration, review, or claim of current upstream API compatibility.
