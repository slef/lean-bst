not merely against build success. Paths are relative to the repository root.

1. Simple unlabelled BST model and conventional-model justification
   Evidence: Models/Rotation/Abstract.lean, Models/Labelled/Abstract.lean,
   Models/Labelled/Ordering/Abstract.lean, Models/Pointer/Abstract.lean, and
   Models/Pointer/Lazy/Online/Abstract.lean (all below RotationBST/).
   Arbitrary inorder key lists determine unique labelled shapes; rotations
   and accesses preserve costs under labelling. Pointer executions simulate
   root accesses, and the reverse simulation has constant overhead with an
   explicitly charged deferred suffix. The online transformer is causal.
   Cost normalization includes a request charge; zero-rotation root accesses

3. Sleator–Tarjan's nine numbered results
   Evidence: Algorithms/Splay/{Balance,StaticOptimality,StaticFinger,WorkingSet,
   Unified,Updates,Conditional,Snapshot,Scanning}/Abstract.lean.
   Checked assumptions include first-use working-set number n, startup
   allowances for arbitrary initial trees, coverage conditions where startup
   is removed, positive analysis weights, and nonnegative normalized snapshot
   probabilities. The unified theorem uses the fixed-finger 1985 bound.
   Updates use supplied local ranks and ordered forests. Conditional splaying
   bounds restructuring, not total searches. Scanning is linear from any
   initial shape. Constants and implementation variants are listed in README.
   Top-down and semisplaying implementations, comparison-key rank discovery,

14. Optimal static trees: Gilbert–Moore/Knuth recurrence, Yao, Knuth (ROADMAP 5)
   Evidence: Classical/Static/Optimal/Abstract.lean.
   For any interval weight W, the recurrence C(i, j) = W(i, j) +
   min_{i <= r < j} (C(i, r) + C(r + 1, j)) is attained by a tree and is
   at most the subtree-weight cost of every tree on [i, j). If W satisfies the
   quadrangle inequality and is monotone under inclusion, C satisfies the
   quadrangle inequality and the largest optimal roots satisfy
   R(i, j) <= R(i, j + 1) and R(i, j) <= R(i + 1, j). Knuth's algorithm
   returns C(0, n) after examining at most 2n^2 candidate roots (lookups are
   not counted; Lean evaluation time is not claimed). For key weights the
   cost is sum_x w[x](depth x + 1); with request counts it is the static
   search cost, so optCost(counts) is the best static tree for the sequence,
   between a third of the entropy bound and the entropy bound.
   Not claimed: gap (unsuccessful-search) weights as a separate statement,
   Garsia–Wachs or Hu–Tucker, approximate trees (Mehlhorn).

15. A dictionary model (ROADMAP 6)
   Evidence: Models/Dictionary/Definitions/Abstract.lean,
   Models/Dictionary/Abstract.lean, Algorithms/Splay/Updates/Dictionary/Abstract.lean.
   Operations by rank (access, insert at a gap, delete) on trees with node
   data. A step is rotations and data edits around one splice of a node with
   at most one child; the main cost is 1 + the depth of the place of the
   change plus all rotations, data edits are counted separately. Every
   rotation-model execution of m accesses with R rotations is a dictionary
   execution with main cost <= m + 2R; searching without moving costs the
   static search cost; splay access, insert and delete are dictionary steps
   with main cost at most 2, 3 and 2 times splay's charge.
   Not claimed: split and join, a pointer machine with allocation, payload
   data beyond implicit ranks, or a splay Dictionary.Algorithm.
